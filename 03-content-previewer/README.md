# Internal GTM Content Review Dashboard

A lightweight single-page React application built with Vite and TypeScript. It lets a content creator:

- enter a headline;
- choose a format (Article, Graphic Asset, or Event Brief);
- assign target tags;
- see a live preview card update as the form changes;
- submit content to a simulated QA review queue.

## Run locally

From this directory:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Other commands

```bash
npm run build
npm run preview
```
